# 北京交通大学高铁纵横答题脚本

> **仅限北京交通大学选修《高铁纵横》课程的同学个人使用。**
> 请勿公开传播、售卖或用于任何商业用途。本项目与学校、课程组、平台方均无关联。

一个用于「高铁纵横」课程在线考试（`http://59.64.5.158/papers`）的辅助脚本：自动登录、识别滑块验证码、按本地题库匹配答案、自动提交。

---

## 功能

- 自动登录（含滑块拼图验证码的本地识别，不依赖任何外部打码服务）
- 自动列出「我的考试」中所有章节、剩余次数、最高分、开放时间
- 按题干匹配本地题库，答案按**选项原文**定位（选项顺序被打乱也能正确选）
- 开考后随机等待 **5~9 秒**再提交（模拟真人操作）
- 登录失败可当场重填账号密码，主菜单输入 `c` 可随时切换账号

---

## 使用方法

### 方式一：绿色版（推荐给不装 Python 的同学）

1. 到 Releases 下载 `hsr-autoexam-v1.0.0.zip`
2. 解压到任意目录（中文路径也可以）
3. 双击 `启动.bat`
4. 首次运行输入学号和密码（只保存在本机 `config.json`）

> 绿色版内置了精简的 Python 运行时，不需要另外安装任何东西。

### 方式二：源码运行

环境要求：Windows + Python 3.12

```bash
pip install pillow
python run.bat        # 或直接 python main.py
```

`bank.json` 需要和 `main.py` 放在同一目录。

## 风险提示（务必阅读）

1. **账号可能被临时封禁**
   账号密码连续错误 5 次，可能会被封禁 **10 分钟**。脚本登录失败时会提示是否重填，不要反复试错。

2. **不清楚网站是否有反脚本机制**
   目前无法确定平台是否会检测自动化行为，也不清楚老师是否会核查做题时长。
   脚本**唯一的应对措施**是提交前随机等待 5~9 秒。
   经过大量测试暂时没有发现问题，但**无法保证绝对安全**，请自行判断是否使用。

3. **题库来源与时效**
   题库整理自「知行百宝箱」2025 年版本，目前已更新全部 **12 章**。
   根据前几章的实际考试情况，题目大多是老题，题库可正常命中；但**不排除个别新题未覆盖**，遇到未命中的题会留空。

4. **实测情况**
   目前已在 **4 位用户**上实际测试第 **3、4、5、6 章**，均**多次满分通过**。

5. **次数有限**
   每次开考都会消耗一次作答机会，脚本无法撤销。请确认后再输入 `yes`。

## 常见问题

**Q：登录失败怎么办？**
A：检查学号密码；如果连续输错可能被临时封禁 10 分钟，等一会再试。程序会自动提示重填。

**Q：想换账号？**
A：主菜单输入 `c`，直接回车可保留原来的某一项。

**Q：提示"未命中"或"⚠ 答案靠字母兜底"？**
A：说明题库里没有这道题，或题库文字与考卷选项对不上。把题目发出来补充题库即可，**不需要重新打包程序**，替换 `bank.json` 就行。

**Q：提交太快会不会被查？**
A：脚本默认随机等待 5~9 秒。可在 `config.json` 里调整：
```json
{
  "submit_delay_min": 5,
  "submit_delay_max": 9
}
```

## 技术说明

- 考试接口前缀 `/prod-api`，登录后使用 Bearer Token
- 题型：`0` 单选、`1` 多选、`2` 判断
- 选项的 `optionCode` 不是 A/B/C/D，而是 `Q2024...ND` 这类唯一 ID，字母写在选项文本前缀里
- 因此匹配时先按**选项原文**定位，字母只作兜底；实测选项顺序会被打乱
- 滑块验证码用 PIL 做模板匹配定位缺口，纯本地计算
