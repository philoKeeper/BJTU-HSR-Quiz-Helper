高铁答题助手 使用说明
========================================

一、怎么用
1. 把整个文件夹解压到任意位置（路径里不要有特殊符号也可以，中文路径没问题）。
2. 双击「启动.bat」。
3. 第一次运行会让你输入学号和密码，输入后回车。
   - 账号密码只保存在本机同目录的 config.json 里，不会上传到任何地方。
   - 输错了不要紧：登录失败时会提示「是否修改账号/密码后重试」，输 y 就能当场重填。
   - 已经在主界面时想换账号：输入 c（直接回车可保留原来的账号或密码）。
   - 也可以删掉 config.json 重新运行。
4. 程序会列出你所有考试，输入序号即可开始答题。
   - 输入 r 刷新列表，输入 c 修改账号密码，输入 q 退出。
5. 开始前会让你输入 yes 确认，因为每考一次会消耗一次作答机会。

二、它怎么答题
- 题目是从题库随机抽的，本程序用内置题库（bank.json）按题干匹配答案。
- 选项顺序可能被打乱，所以程序按「选项原文」匹配，而不是死记 A/B/C/D。
- 开考后会随机等 5~9 秒再提交（模拟真人，避免秒交被判定异常），然后显示得分。
- 想改等待区间：在 config.json 里加 "submit_delay_min": 5, "submit_delay_max": 9。
  只写 "submit_delay": 8 表示固定等 8 秒；填 0 表示不等待。

三、注意事项
- 每门考试有次数限制，考一次少一次，请确认后再输入 yes。
- 题库覆盖不到的题会留空，提交后显示命中数量，可据此判断是否需要更新题库。
- 本工具仅供个人账号使用，请遵守学校考试纪律；因使用产生的后果由使用者自行承担。

四、文件说明
- 启动.bat        双击启动
- main.py         主程序
- bank.json       题库（263 题，第 1-12 章）
- hsr_client.py   登录 / 验证码 / 考试接口
- hsr_bank.py     题库匹配
- hsr_aes.py      验证码加密
- runtime\        内置 Python 运行环境（无需另外安装 Python）
- config.json     你的账号密码（首次运行后生成）

五、常见问题
Q: 提示「登录失败」？
A: 检查账号密码；连续输错会被临时封禁 10 分钟，等一会再试。

Q: 提示「该考试当前不可作答」？
A: 不在考试时间窗口内，或次数已用完。

Q: 想更新题库？
A: 用同格式的 JSON 覆盖 bank.json 即可：
   [{"question": "题干", "answer": "A", "answer_options": [{"letter":"A","text":"选项原文"}]}]
